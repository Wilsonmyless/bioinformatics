Your first R expression

Start by asking R to calculate something. This is the same console you’ll use to inspect real datasets later.

R is a calculator—and much more

R evaluates expressions and returns a result. For example, 2 + 2 evaluates to 4. In bioinformatics, you’ll use the same idea to transform measurements, summarize samples, and make plots.

Research note  A calculation is only as meaningful as its inputs. We’ll keep track of what each value represents as we move from toy examples to biological measurements.

LESSON 2 OF 4 · R FOUNDATIONS

Give your measurements a name

R objects hold data so you can reuse it. Vectors let you keep related measurements together in their original order.

Store related values in a vector

In R, <- assigns a value to a name. The function c() combines values into a vector. Here, we’ll use a tiny teaching example of gene read counts from four samples.

Biology note  These are invented counts for practicing R syntax, not experimental results. Real RNA-seq counts need sample metadata, quality checks, and an analysis method matched to the experiment.
